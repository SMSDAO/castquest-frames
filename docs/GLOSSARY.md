# CastQuest Glossary

> Comprehensive terminology reference for the CastQuest protocol

---

## A

### Admin Dashboard
The administrative interface for protocol operators and administrators. Provides system monitoring, risk management, token controls, and permission management. Runs on port 3010.

### AI Brain
See **Smart Brain**

### Autonomous Worker System
Background job processing system that handles tasks like frame processing, quest validation, and data synchronization. Features parallel execution and self-healing capabilities.

---

## B

### Base
Layer 2 Ethereum scaling solution built by Coinbase. Primary blockchain network for CastQuest protocol smart contracts.

### Brain Events
Events generated by the Smart Brain system during analysis, pattern recognition, and decision making. Logged for audit and learning purposes.

---

## C

### CAST Token
Primary protocol token (ERC-20) with 100M max supply. Used for governance, fees, and protocol incentives.

### CastQuest
Web3-native social photo protocol where media becomes mintable, collectible, and programmable through Frames.

### Core Services
Backend API layer providing REST endpoints for users, wallets, media, markets, and risk management. Runs on port 4000.

### Creator-First
Design principle emphasizing creator ownership, control, and monetization of content.

---

## D

### Dashboard
User interface for interacting with the protocol. Two types: User Dashboard (creators) and Admin Dashboard (operators).

### Deep Thinking
Advanced AI analysis mode in Smart Brain that performs multi-dimensional pattern recognition and predictive analytics.

### Drizzle ORM
TypeScript ORM used for database operations in Core Services. Provides type-safe database queries.

---

## E

### ERC-20
Ethereum token standard. Used for CAST token and media tokens.

### Event-Driven Architecture
Design pattern where components communicate through events. Used in Smart Brain and Worker systems.

### EVM
Ethereum Virtual Machine. CastQuest contracts are EVM-compatible and can deploy to any EVM chain.

---

## F

### Farcaster
Decentralized social protocol. CastQuest implements Farcaster Frames specification for social integration.

### Fee Router
Smart contract that manages protocol fee distribution across stakeholders.

### Frame
Core content unit in CastQuest. JSON-defined interactive mini-app that combines UI, logic, and onchain actions. Can be a mint, quest, game, or airdrop.

### Frame Template
Reusable frame definition that can be applied to multiple media items. Enables marketplace of frame designs.

### Frames Oracle
Package implementing Farcaster Frames with market signals, token details, and protocol overview. Runs on port 3002.

### Foundry
Solidity development framework used for smart contract compilation, testing, and deployment.

---

## G

### Glassmorphism
Design technique using transparent backgrounds with blur effects. Core element of Neo Glow theme.

### Glow Effect
Visual effect using CSS shadows to create illuminated appearance. Signature of CastQuest design system.

---

## H

### Health Check
System validation that verifies all components are operational. Includes structure, dependencies, and runtime checks.

---

## I

### Indexer
Service that monitors blockchain events and updates offchain database. Enables fast queries of onchain data.

---

## J

### JWT (JSON Web Token)
Authentication token format used for API authentication. Contains user claims and expires after 7 days.

---

## L

### Layer 2 (L2)
Blockchain scaling solution that processes transactions off main chain. Base is the primary L2 for CastQuest.

---

## M

### Market Signal
Real-time indicator of token performance including price, volume, and percentage change. Displayed in Frames.

### Master Orchestrator
Central command script (`master.sh`) that manages all system operations including deployment, health checks, and monitoring.

### Media Registry
Smart contract and offchain database tracking all media items, metadata, and risk flags.

### Media Token
Per-media ERC-20 token created through MediaTokenFactory. Represents ownership/access to specific media.

### Media Token Factory
Smart contract that creates new media tokens with configurable fees and supply.

### Mint
Process of creating NFTs or tokens. Also refers to the resulting tokenized asset.

### Module
Self-contained component of the protocol. Modules M4-M8 cover different aspects: API, Quests, Templates, Mints, and Workers.

### Monorepo
Repository structure where multiple related packages are managed together. CastQuest uses pnpm workspaces.

---

## N

### Neo Glow
CastQuest's design system featuring purple/cyan/pink gradients, glassmorphism, and glow effects.

### Neo UX Core
Package containing core UI components with Neo Glow styling. Built on React and Radix UI.

### Next.js
React framework used for User and Admin dashboards. Version 14 with App Router.

---

## O

### Onchain
Data or operations stored/executed on blockchain. Opposite of offchain.

### Oracle Database
Enterprise database system with parallel sync, connection pooling, and Smart Brain integration.

### Orchestrator
See **Master Orchestrator**

---

## P

### Pattern Recognition
Smart Brain capability to identify trends, anomalies, and relationships across multiple data dimensions.

### Permission System
Role-based access control (RBAC) with 19 granular permissions across 4 predefined roles.

### pnpm
Fast, disk-efficient package manager. Required version 9+ for CastQuest development.

### Protocol
Set of rules and standards defining how CastQuest operates. Includes smart contracts, APIs, and frame specifications.

---

## Q

### Quest
Gamified challenge or mission users can complete for rewards. Managed through Quest Engine.

### Quest Engine
Module M5B handling quest creation, progress tracking, and reward distribution.

---

## R

### RBAC (Role-Based Access Control)
Security model where permissions are assigned to roles, and roles are assigned to users.

### Risk Management
System for detecting and flagging problematic content including spam, NSFW, and scams. Uses AI-powered detection.

### Role
Named collection of permissions. Predefined roles: Super Admin, Admin, Moderator, Viewer.

---

## S

### SDK (Software Development Kit)
TypeScript library for integrating with CastQuest protocol. Provides type-safe API client and utilities.

### Self-Healing
Capability of system to automatically detect and repair issues without manual intervention.

### Smart Brain
AI-powered orchestration system with deep thinking, pattern recognition, and autonomous decision making.

### Smart Contract
Self-executing code deployed on blockchain. CastQuest uses Solidity contracts on Base.

### Solidity
Programming language for Ethereum smart contracts. Version 0.8.23 used in CastQuest.

### Strategy Worker
Background process that executes automated strategies and workflows. Part of Autonomous Worker System.

### Sync Interval
Time between data synchronization operations. Default 5 seconds for Oracle sync.

---

## T

### Template
See **Frame Template**

### Token
Digital asset on blockchain. CastQuest includes protocol token (CAST) and media tokens.

### TypeScript
Typed superset of JavaScript. Primary language for CastQuest development.

---

## U

### User Dashboard
Interface for creators to build frames, track analytics, and engage with community. Runs on port 3000.

---

## V

### Vercel
Cloud platform for deploying Next.js applications. Recommended for dashboard deployments.

### viem
TypeScript library for Ethereum interactions. Used for blockchain operations in CastQuest.

---

## W

### Wallet
Cryptocurrency account that holds tokens and signs transactions. CastQuest supports EOA and smart wallets.

### Web3
Decentralized web powered by blockchain technology. CastQuest is a Web3 protocol.

### Worker
Background process that executes tasks asynchronously. See **Autonomous Worker System**.

### Workspace
pnpm workspace enabling monorepo management. Allows sharing dependencies across packages.
