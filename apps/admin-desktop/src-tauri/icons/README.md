# Icon Placeholder

Place your application icons in this directory:

- `32x32.png` - 32x32 pixels
- `128x128.png` - 128x128 pixels  
- `128x128@2x.png` - 256x256 pixels
- `icon.icns` - macOS icon
- `icon.ico` - Windows icon

You can generate these icons using tools like:
- https://www.icoconverter.com/
- https://icon.kitchen/
- https://tauri.app/v1/guides/features/icons/

For now, Tauri will use default icons during development.
